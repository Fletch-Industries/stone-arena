# Contributing to Stone Arena

Feature ideas and bug reports are welcome in
[GitHub Issues](https://github.com/Fletch-Industries/stone-arena/issues).
Choose **Feature request** to describe your idea or **Bug report** to provide
reproduction steps and your device/browser. Search existing issues first so related
feedback stays together. Do not share private room links or personal information.

For code changes, fork the repository, create a branch, and open a pull request
against `main`. Include a short explanation and relevant verification. See the
README for local setup; run `npm test` and `npm run build` before submitting.
Changes affecting multiplayer should also run the protocol tests against a local
server. Please discuss larger gameplay changes in an issue before implementing them.

Keep code, art, textures, and audio original or clearly document their permitted
source. This project does not distribute Minecraft assets.
